# Historial de cambios

Este proyecto sigue [Versionado Semántico](https://semver.org/lang/es/).

## 1.0.0 - 2026-08-29

Primera versión pública estable de Sharki Desktop Guardian.

### Incluye

- Monitorización local de CPU, GPU NVIDIA, RAM, discos y red.
- Reconocimiento y síntesis de voz sin conexión.
- Icono y menú en la bandeja del sistema.
- Control rápido para silenciar o reactivar las respuestas habladas.
- Panel movible con posición persistente.
- Alertas compactas que identifican la métrica responsable.
- Modo demostración, tutorial y arranque robusto sin SAPI.
- Aplicación portátil autocontenida para Windows 11 x64.
- Compilación, diagnóstico y publicación automatizados con GitHub Actions.
